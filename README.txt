Plugin to import GNG data into QGIS project for QGIS-AVISO for VATSIM French vACC

Copy data from GNG into a text file.

* Label Gate should go into LFXX Gates.txt (e.g. LFST Gates.txt)
* Label Taxiways should go into LFXX Taxiways.txt (e.g. LFST Taxiways.txt)
* SCT ENtries Groundlayout AVISO should go into LFXX Groundlayout AVISO.txt (e.g. LFST Groundlayout AVISO.txt)
* Regions AVISO entries shuold go into LFXX AVISO.txt (e.g. LFST AVISO.txt)

Use the plugin button and choose the file you want to import

!! Naming of the files is important to import under the right layer !!
If layer does not exist it will be created
